    *   After submission, provide a popup to download Firegold's Health Canada and CRA licenses.
5.  **Submission Tracker:** A public page for growers to track their submission status.
6.  **Admin Panel:**
    *   **Dashboard:** Comprehensive analytics and a total inventory summary.
    *   **Content Management:** Add, edit, and remove strains.
    *   **User Management:** Manage users with pause/restore/remove access. Features a robust user profile modal showing login history, viewed strains, and inquiries made.
    *   **Submission Review:** Review grower submissions.
    *   **Master Directory:** Master list of all strains, with the ability to add missing license numbers.
    *   **Inquiry Hub:** Centralized place to view and manage all user inquiries.
    *   **Affiliate Management:** A tab to create and manage affiliates with custom referral codes.
7.  **Affiliate System:** Allow approved affiliates to share a custom URL (). Track referred user sign-ups and credit affiliates for sales generated from those users (when an admin marks an inquiry as converted). Affiliates need a dashboard to view their stats.
8.  **Authentication:** JWT-based auth for users and admins. User profiles include a .
