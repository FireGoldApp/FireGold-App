The user wants to build a B2B database catalog for cannabis whole flower sales called Firegold.

**PRODUCT REQUIREMENTS:**
1.  **Catalog:** Display cannabis strains with details (name, THC, lineage, terpenes, effects, lot size, images). The entire catalog must be protected behind a user login.
2.  **Branding:** Use the Firegold logo and a dark theme with gold accents. The logo should be prominent.
3.  **Sample Requests:** Allow registered users to request samples, requiring them to upload Health Canada and CRA license PDFs.
4.  **Grower Submissions:** Provide a public-facing form for growers to submit their flower to be added to the app. This form should include strain details, image uploads, and document uploads (COA, Health Canada License, CRA License). 5.  **Submission Tracker:** A public page for growers to track the status of their submissions (Pending, Approved, Rejected).
6.  **Admin Panel:**
    *   Secure login for administrators at the  route.
    *   Dashboard with comprehensive analytics (user activity, engagement, global insights).
    *   Manage strain images (update/delete).
    *   Add, **edit**, and remove strains from the catalog.
    *   Manage registered users and review flagged duplicate registrations.
    *   Review grower submissions, approve/reject them, and set the price.
    *   Manage Certificate of Analysis (COA) PDFs for each strain, including uploading a redacted version.
7.  **Certificate of Analysis (COA):** Users should be able to view the COA for a strain from the catalog via an in-app PDF viewer.
8.  **Access Control & Auth:**
    *   JWT-based authentication for users and a separate admin role.
    *   Users should register with a self-chosen password.
    *   Prevent non-admin users from downloading or saving images.
9.  **Analytics & Data Export:**
    *   Track detailed user navigation patterns (clicks, views, searches, COA views, time spent).
    *   Display aggregated and individual user analytics in the admin dashboard.
    *   Allow exporting analytics data to CSV.
